# Repository Structure (Research View)

This repository is organized for OpenClaw research with a clear split:

- `source area`:
  OpenClaw original source and official docs remain in their original locations:
  `src/`, `apps/`, `extensions/`, `ui/`, `docs/`, `scripts/`, etc.

- `research area`:
  All custom analysis documents live in `research/`.

Quick start:

- Read `/research/README.md`
- Then read `/research/OPENCLAW_RESEARCH_SUMMARY.zh-CN.md`
